# Publication checklist for future releases

- [x] Public README and independent-project status explicit.
- [x] Current manuscript excluded from repository.
- [x] No individual student records or university correspondence included.
- [x] Proposed pilot and outcome claims labelled as **not conducted**.
- [x] No official endorsement or university approval implied.
- [ ] Author review of current manuscript version and public terminology.
- [ ] Verify any stated legal rules against current primary Panjab University instruments.
- [ ] Scrutinise citations, originality, quotations and rights.
- [ ] Audit future uploaded documents for addresses, phone numbers, emails, student identifiers, metadata and hidden layers.
- [ ] Conduct expert review and transparently state any disagreements.
- [ ] Publish any empirical results only with consent, methodology, appropriate ethical review and uncertainty measures.

**Do not put unpublished draft PDFs, evaluated scripts, RTI records or raw grievance correspondence in this public repository.**
