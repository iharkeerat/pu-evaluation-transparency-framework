# 3 · Marking standards and partial credit

## Design hypothesis

A more explicit record of the evidence used to award marks **might** improve clarity, consistency and reviewability. Whether it does so requires subject-specific piloting, not assertion.

### Matters to examine

- **Paper-specific expectations:** Identify learning outcomes, essential steps, conceptual understanding and legitimately acceptable methods.
- **Alternative valid answers:** Avoid treating an examiner's model answer as the only permissible reasoning when another method satisfies the same learning outcome.
- **Partial credit:** Explain whether method, setup, intermediate reasoning, units, interpretation and final results can receive distinct credit.
- **Internal consistency:** Record when different markers encounter comparable response patterns.
- **Transparency:** Publish appropriate criterion information without disclosing material that would compromise a live secure examination.

### Discipline-sensitive evaluation

A numerical proof, a coding explanation, a historical essay, a literary interpretation, a practical demonstration and an oral performance should **not** use one universal scoring grid. Each needs defensible criteria and calibrated human judgement.

### Candidate indicators for a future study

- Agreement on sample scripts between qualified examiners.
- Reasons for inter-rater discrepancies.
- Frequency of documented alternative valid methods.
- Time burden of criterion-based recording.
- Whether the added detail actually helps students understand outcomes.

No observed values are reported here. See the [proposed pilot](../research/pilot-and-validation-plan.md).
